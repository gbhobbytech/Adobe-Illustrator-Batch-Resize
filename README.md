\# Adobe Illustrator Batch Resize



A free Adobe Illustrator script for resizing multiple selected objects to a specified height in millimetres while maintaining their original proportions.



Supports vector artwork, groups, embedded images and linked images.



\## Features



\- Resize multiple selected objects in one operation.

\- Enter the target height in millimetres.

\- Maintain each object's aspect ratio.

\- Support paths, compound paths, groups, embedded raster images and linked images.

\- Refresh the Illustrator display before showing the results.

\- Report the number of successfully resized and skipped objects.

\## Installation



1\. Download `BatchResizeV2ImageEnabled.jsx` from the latest GitHub Release.

2\. Open Adobe Illustrator.

3\. Open the document containing the objects you want to resize.

4\. Select the objects.

5\. Choose \*\*File > Scripts > Other Script...\*\*

6\. Locate and open the downloaded `.jsx` file.



The script can also be installed in Illustrator's Scripts directory for easier access.



\## Usage



1\. Select one or more objects.

2\. Run the script.

3\. Enter the required height in millimetres.

4\. Click OK.

5\. Illustrator resizes the supported objects proportionally and displays a completion summary.



Each selected object is resized individually to the specified height.



\## Supported Objects



\- Paths

\- Compound paths

\- Groups

\- Embedded raster images

\- Linked or placed images



\## Limitations



\- Only explicitly supported object types are processed.

\- Objects with zero height are skipped.

\- Locked or otherwise unmodifiable objects may be skipped.

\- The script uses Illustrator's visible bounds, which include stroke width.

\- Compatibility across Illustrator versions has not yet been comprehensively tested.
